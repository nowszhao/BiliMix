BiliMix

把英文播客、音频和视频逐句译成中文，再用原说话人的音色读出来。

默认逐句替换为原音色的中文配音，把 sentence_cn_ratio 调到 0.5 就是中英交替讲述；视频模式再烧录双语字幕。还内置播客订阅更新、查词与独立语音合成，全程本机推理。

一键安装 查看源码
全本地推理 Python 3.10 macOS / Linux MIT
效果

同一段视频，配音前后

英文原声保留，中文译文用原说话人的音色插入，字幕同步双语显示。

特性

为“听得懂”而做的每一步

逐句对齐的中英交替，而不是整段替换；每个环节都能单独调参或重跑。

原音色配音

Confucius4-TTS 零样本克隆说话人音色读中文译文，逐句替换原声。

中英比例可调

sentence_cn_ratio：1.0 逐句全中文，0.5 中英交替，0 保留原声；可选保留 BGM。

视频配音与字幕

YouTube、本地 MP4、服务器路径 → 配音 MP4，字幕双语 / 纯中文 / 不烧录，可加水印。

已有字幕直接配音

上传双语 .ass / .srt，跳过转录与翻译，直接进入语音合成。

播客订阅与更新

iTunes 搜索 + RSS 订阅，定时抓取更新、未读统计、收藏与搜索历史。

命令行与 API

任务按步骤落盘、失败从断点重试；bmx CLI 与 REST API 覆盖全流程。

快速开始

一条命令装好，两条命令跑起来

安装脚本幂等：已完成的步骤自动跳过，环境坏了重跑一次即可。

安装
curl -fsSL https://raw.githubusercontent.com/nowszhao/BiliMix/main/setup.sh | bash

已 clone 仓库时运行 ./setup.sh。脚本会准备 conda 环境 bilimix（Python 3.10）、FFmpeg 与 Ollama、Python 依赖，并把 Confucius4-TTS-CPU 放到同级目录。

启动
# 首次需要：启动 Ollama 并拉取翻译模型 ollama serve ollama pull translategemma:4b # 启动服务，端口可省略（默认 5000） conda activate bilimix python services/web_app.py 5555

打开 http://localhost:5555 即可使用。启动时强制检测硬件与依赖，缺失直接退出并给出修复命令。

资源最低推荐说明
CPU4 核8 核+转录 8 线程 + TTS worker + FFmpeg 编码
内存8 GB16 GB+Ollama 3-4 GB + TTS 2-4 GB/worker（CPU 默认 1 个）
磁盘15 GB50 GB+Python 环境 + 模型约 10 GB + 音视频缓存
GPU不需要可选 6 GB+显著加速 TTS 与 WhisperX

内存是主要瓶颈。低配机器：翻译模型用 translategemma:4b、TTS worker 降为 1、WhisperX 用 small。

命令行

把整套能力交给脚本

bmx 包装了 Web 服务的全部 REST API，适合批处理与 AI Agent 调用。

# 安装 pip install -e sdk/ # 音频：URL 或本地文件 → 中英交替 MP3 bmx task submit --url https://example.com/episode.mp3 --wait bmx audio download --task-id <task_id> -o mixed.mp3 # 视频：YouTube 或服务器路径 → 配音 MP4 + 字幕 bmx task submit --type video --video-url "https://www.youtube.com/watch?v=xxx" --wait bmx video download --task-id <task_id> -o dubbed.mp4 # 独立语音合成：参考音频 + 文本 bmx tts synth --ref-audio ./ref.wav --text "要合成的话" --wait -o out.wav

完整命令见 sdk/README.md 与 sdk/docs/cli.md。服务地址默认 http://localhost:5000，可用 BILIMIX_SERVER 覆盖。
